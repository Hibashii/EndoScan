# EndoScan 🧪

**Les perturbateurs endocriniens et leur impact sur la santé thyroïdienne**

Application web de data visualisation + scanner de produits pour identifier les perturbateurs endocriniens thyroïdiens dans les cosmétiques et l'alimentation.

## Structure du projet

```
thyroguard/
├── frontend/     → React + Vite + Tailwind CSS
├── backend/      → Python + FastAPI 
└── README.md
```

## Stack technique

- **Frontend** : React, Vite, Tailwind CSS, Recharts, QuaggaJS
- **Backend** : Python, FastAPI, Pandas
- **Données** : Open Food Facts, Open Beauty Facts, TEDX List

## Quick start

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend (à venir)
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```
